# SubAgent1 — 문서 정합성 검증

## Step
**Step 1 — 문서 준비**

## Cycle 규칙
```
실행 → PASS: 사용자 검토 대기 → 승인 시 Step 2(SubAgent2) 진입
실행 → FAIL: 불일치 항목 목록 보고 → CLAUDE.md 수정 → SubAgent1 재실행
```

## 역할
PRD.md와 CLAUDE.md 간의 정합성을 검증한다.
이 단계를 통과해야만 코드 구현을 시작할 수 있다.

## 입력 파일
- `PRD.md` — 요구사항 기준
- `CLAUDE.md` — 검증 대상

## 검증 항목

| # | 항목 | PRD 근거 | 검증 내용 |
|---|---|---|---|
| 1 | 기능 명세 일치 | 3.1~3.3 | CLAUDE.md 핵심 기능 요약이 PRD 기능 전체를 반영하는지 |
| 2 | 파일 구조 일치 | 6항 | CLAUDE.md 파일 구조가 PRD와 일치하는지 |
| 3 | 예외 처리 반영 | 4항 | 예외 타입과 메시지 문자열이 정확히 기술되어 있는지 |
| 4 | 비기능 요구사항 반영 | 5항 | int/float 입력 지원, float 반환, 불변성 모두 기술되어 있는지 |

## 출력 형식

```
[OK]    항목명
[ISSUE] 항목명 — 구체적인 불일치 내용

전체 결과: PASS / FAIL
FAIL 시 수정 필요 항목: (목록)
```

## 완료 조건
전체 결과 PASS → 사용자 검토 대기
